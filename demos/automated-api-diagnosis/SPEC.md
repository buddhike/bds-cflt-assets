For each API, the simulater should be able to output logs to Kafka topic. 

When starting the application, it should ask for my Confluent Cloud credentials and setup a Standard Kafka cluster along with necessary topic and service account for the simulator. It should deploy these resources using Terraform. Simulator should work without having to install terraform beforehand. 

For each application, following items should be adjustable.
- Rate at which logs are generated
- Rate at which HTTP 500 records are generated
- Rate at which HTTP 403 records are generated
- Rate at which HTTP 404 records are generated
- Response time of upstream API
- Ability to simulate errors at the gateway with a toggle - When this happens response time of upstream API is -1. 

I should be able to simulate a dependency between two APIs and simulate a cascading effect of failures. 

Simulator should be built with Wails framework for Go so that I can run it as a standalone app.
